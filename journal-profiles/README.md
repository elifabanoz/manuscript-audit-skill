# Journal profile fixtures

Profiles here contain short rule quotations, source URLs, retrieval times, and hashes. They do not contain cached guideline pages or manuscript text. Each profile is a dated snapshot: fetch the cited official pages into a private run and compare their hashes before using its rules. If a page has changed, rebuild the profile from the new text. A rule marked `needs_validation` cannot support a confirmed finding.
